# Memory-Aware Conversational Assistant
A memory-aware conversational AI assistant with contextual understanding and persistent memory.traning models with exported chat histories

## Overview
A conversational AI system that remembers previous interactions
and responds with contextual awareness.

## Goals
- Persistent memory
- Context tracking
- Personalized conversations
- Efficient retrieval system

## Tech Stack
- Java / Python
- React
- PostgreSQL
- OpenAI API

## Project Stages
1. Planning
2. Basic chatbot
3. Memory system
4. Context management
5. Frontend UI
6. Deployment
